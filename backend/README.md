# Fire Season data contracts

The Competition MVP uses an artifact-first backend. Implement against:

- `schemas/analysis-artifact.schema.json`
- `schemas/evidence-receipt.schema.json`
- `schemas/release-manifest.schema.json`
- the analytical table and publication rules in `docs/06-BACKEND-SCHEMA.md`

`schema.sql` and `openapi.json` are preserved as post-MVP references from an earlier production-service design. They are not part of the hackathon application, deployment, or test path.
