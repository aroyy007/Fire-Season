# Use an artifact-first, offline-capable MVP

The Competition MVP will consume immutable Analysis Artifacts generated by a reproducible Python pipeline rather than depending on live Earthdata access, model fitting, user accounts, a database, or a job queue during judging. A minimal API may serve artifacts only when it simplifies deployment. This trades live arbitrary analysis for a faster, reliable demonstration in which every displayed value has already passed the scientific release gates and remains usable without network access.
