# 02: Browse the Science Pilot native seasonal calendar

**What to build:** Extend the native artifact into a year-by-month Burning Activity Calendar for the Science Pilot. A Monitoring Analyst can browse the available months, see the MODIS–VIIRS era boundary, and distinguish detected activity, valid zero, and unavailable observation support.

**Blocked by:** 01: Show Native Sensor Records from one paired sample.

**Status:** ready-for-agent

- [ ] The artifact contains ordered monthly native records for the declared period.
- [ ] The calendar renders year rows and month columns from released artifact data.
- [ ] The sensor-era boundary and product identity are visible without a tooltip.
- [ ] No observation, observed zero, and detected activity have distinct text and visual states.
- [ ] The calendar remains usable at the narrow layout described in the app-flow specification.
